# План: Переключатель UTC / Местное время на экране «Журнал»

## Проблема
`timeSec` — Unix timestamp (UTC). Сейчас `SimpleDateFormat` без явного TZ использует локальный пояс → данные фактически показываются в местном времени. Пользователь не знает, в каком времени видит данные.

## Решение
Добавить Switch «Показывать местное время» на JournalScreen. По умолчанию выключен (UTC). При включении — время сдвигается на поясной час телефона. Один переключатель влияет на таблицу, график, сводку. Состояние сохраняется в prefs.

### 3. `app/src/main/java/com/example/bthviewing/JournalScreen.kt`

**3a. Добавить состояние переключателя с сохранением в prefs:**
```kotlin
val prefs = context.getSharedPreferences("journal_prefs", Context.MODE_PRIVATE)
var showLocalTime by remember {
    mutableStateOf(prefs.getBoolean("show_local_time", false))
}
// Сохранение при изменении (LaunchedEffect)
LaunchedEffect(showLocalTime) {
    prefs.edit().putBoolean("show_local_time", showLocalTime).apply()
}
```

**3b. Добавить Row с переключателем и подписью режима — после строки со статусами Wi-Fi/Bluetooth и перед кнопками действий:**
```kotlin
if (state.records.isNotEmpty()) {
    Spacer(Modifier.height(8.dp))
    Row(verticalAlignment = Alignment.CenterVertically) {
        Text(
            text = if (showLocalTime) stringResource(R.string.time_mode_local)
                   else stringResource(R.string.time_mode_utc),
            fontSize = 12.sp,
            fontWeight = FontWeight.Bold,
            color = MaterialTheme.colorScheme.primary
        )
        Spacer(Modifier.width(8.dp))
        Switch(
            checked = showLocalTime,
            onCheckedChange = { showLocalTime = it }
        )
        Spacer(Modifier.width(8.dp))
        Text(
            text = stringResource(R.string.time_mode_label),
            fontSize = 12.sp,
            color = MaterialTheme.colorScheme.onSurfaceVariant
        )
    }
}
```

**3c. Передать `showLocalTime` в `RecordsTable`:**
```kotlin
RecordsTable(state.records, showLocalTime = showLocalTime)
```

**3d. Передать `showLocalTime` в `HistoryChart`:**
```kotlin
HistoryChart(
    records = chartRecords,
    periodLabel = ...,
    showLocalTime = showLocalTime,
    modifier = Modifier.fillMaxSize()
```

**3e. Обновить `RecordsTable` — принимать `showLocalTime`, форматировать с нужным TZ:**
```kotlin
@Composable
fun RecordsTable(records: List<MemoRecord>, showLocalTime: Boolean) {
    val fmt = remember(showLocalTime) {
        SimpleDateFormat("dd.MM.yyyy HH:mm", Locale.getDefault()).apply {
            timeZone = if (showLocalTime) TimeZone.getDefault() else TimeZone.getTimeZone("UTC")
        }
    }
    ...
}
```

**3f. Обновить `SummaryText` — принимать `showLocalTime`, форматировать даты с нужным TZ:**

### 4. `app/src/main/java/com/example/bthviewing/ui/chart/HistoryChart.kt`

**4a. Добавить параметр `showLocalTime: Boolean` в сигнатуру:**
```kotlin
@Composable
fun HistoryChart(
    records: List<MemoRecord>,
    periodLabel: String = "day",
    showLocalTime: Boolean = false,
```

**4b. Обновить все 4 формата подписей оси X и 1 формат плашки — добавить TZ:**
```kotlin
val hmFmt = remember(showLocalTime) {
    SimpleDateFormat("HH:mm", Locale.getDefault()).apply {

val dmFmt = remember(showLocalTime) { ... }
```

**4c. Обновить подпись оси X (в Canvas, цикл xTicks):**
```kotlin

    timeInMillis = tSec * 1000L
}
// →
val cal = Calendar.getInstance().apply {
    timeZone = if (showLocalTime) TimeZone.getDefault() else TimeZone.getTimeZone("UTC")

```

**4d. Обновить плашку выбранной точки:**


## Что не трогать
- `CsvExporter.kt` — экспорт остаётся в UTC
- `JournalViewModel.kt` — `timeSec` в UTC, это правильно
- `MemoRecord.kt` — не трогать
- `GattMemoClient.kt`, `GattConfigClient.kt` — не трогать
- `SettingsScreen.kt` — своё время, не связано
- `MainViewModel.kt` — не трогать (prefs храним в JournalScreen напрямую)

## Верификация
1. Собрать: `./gradlew assembleDebug`
2. Журнал, переключатель выключен — таблица/график/сводка в UTC (подпись «UTC»)
3. Журнал, переключатель включён — таблица/график/сводка в местном времени (подпись «Местное»)
4. Переключение — синхронно для таблицы и графика
5. Перезапуск — переключатель сохраняет состояние
6. CSV — не изменился (UTC)
