# План: Удаление хардкод-строк из BthomeScanner.kt

## Проблема
В `BthomeScanner.kt` есть 2 хардкод-строки, которые не локализованы.

## Хардкод-строки для переноса в strings.xml
1. `"BLE scanner недоступен"` → `err_ble_scanner_unavailable`
2. `"Scan failed: $errorCode"` → `err_scan_failed_code` (уже есть в RU, но нет в EN)

## Изменения

### 1. `app/src/main/res/values/strings.xml` — проверить наличие строк
Строка `err_scan_failed_code` уже есть:
```xml
<string name="err_scan_failed_code">Scan failed: %1$d</string>
```
Нужно заменить на русский перевод:
```xml
<string name="err_scan_failed_code">Сканирование не удалось: %1$d</string>
```

Добавить новую строку:
```xml
<string name="err_ble_scanner_unavailable">BLE scanner недоступен</string>
```

### 2. `app/src/main/res/values-en/strings.xml` — добавить/проверить строки
Добавить:
```xml
<string name="err_scan_failed_code">Scan failed: %1$d</string>
<string name="err_ble_scanner_unavailable">BLE scanner unavailable</string>
```

### 3. `app/src/main/java/com/example/bthviewing/BthomeScanner.kt` — заменить хардкод на `context.getString`
**Было:**
```kotlin
close(IllegalStateException("BLE scanner недоступен"))
```
**Стало:**
```kotlin
close(IllegalStateException(context.getString(R.string.err_ble_scanner_unavailable)))
```

**Было:**
```kotlin
close(IllegalStateException("Scan failed: $errorCode"))
```
**Стало:**
```kotlin
close(IllegalStateException(context.getString(R.string.err_scan_failed_code, errorCode)))
```

## Влияние
- 3 файла: `strings.xml`, `strings-en.xml`, `BthomeScanner.kt`
- Все пользовательские строки локализованы
- Сборка и проверка

1. Собрать: `./gradlew assembleDebug`
2. Проверить, что ошибки сканирования отображаются на русском/английском в зависимости от языка
