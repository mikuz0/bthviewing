# План: Статус Bluetooth на страницах "Журнал" и "Настроить датчик"

## Проблема
Статус Bluetooth отображается только на экране "Устройства" (ListeningStatus). На страницах "Журнал" и "Настройки" пользователь не видит, выключен ли Bluetooth.

## Решение
Добавить статус Bluetooth в строку со статусом Wi-Fi на обеих страницах. Использовать `mainViewModel.uiState.bluetoothReady` (обновляется через BroadcastReceiver в MainActivity). Блокировать кнопки при выключенном Bluetooth.

## Файлы для изменения

### 1. `app/src/main/res/values/strings.xml` — новые строки
Добавить:
```xml
<string name="status_bluetooth_on">Bluetooth включён</string>
<string name="status_bluetooth_off">Bluetooth выключен</string>
```

### 2. `app/src/main/res/values-en/strings.xml` — новые строки
Добавить:
```xml
<string name="status_bluetooth_on">Bluetooth is on</string>
<string name="status_bluetooth_off">Bluetooth is off</string>
```

### 3. `app/src/main/java/com/example/bthviewing/JournalScreen.kt`

**3a. Добавить чтение bluetoothReady из MainViewModel:**
```kotlin
val mainState by mainViewModel.uiState.collectAsState()
val bluetoothReady = mainState.bluetoothReady
```

**3b. Добавить статус Bluetooth в строку со статусом Wi-Fi:**
Заменить текущий `Text` со статусом Wi-Fi на `Row`:
```kotlin
Row(verticalAlignment = Alignment.CenterVertically) {
    Text(
        text = if (wifiText.contains(context.getString(R.string.wifi_on)))
            "⚠️ Wi-Fi включён"
        else
            "✅ Wi-Fi выключен",
        fontSize = 14.sp,
        fontWeight = FontWeight.Bold,
        color = if (wifiText.contains(context.getString(R.string.wifi_on)))
            MaterialTheme.colorScheme.error
        else
            Color(0xFF2E7D32)
    )
    Spacer(Modifier.width(16.dp))
    Text(
        text = if (bluetoothReady)
            "🔵 Bluetooth включён"
        else
            "🔴 Bluetooth выключен",
        fontSize = 14.sp,
        fontWeight = FontWeight.Bold,
        color = if (bluetoothReady)
            Color(0xFF2E7D32)
        else
            MaterialTheme.colorScheme.error
    )
}
```

**3c. Блокировка кнопки "Считать данные" при выключенном Bluetooth:**
```kotlin
enabled = state.deviceAddress != null && !state.isReading && !isWifiEnabled && !bluetoothReady
// →
enabled = state.deviceAddress != null && !state.isReading && isWifiEnabled && bluetoothReady
```

Нет, лучше сохранить логику:
```kotlin
enabled = state.deviceAddress != null && !state.isReading && !isWifiEnabled && !bluetoothReady
```
— кнопка заблокирована, если Wi-Fi включён ИЛИ Bluetooth выключен.

### 4. `app/src/main/java/com/example/bthviewing/SettingsScreen.kt`

**4a. Добавить чтение bluetoothReady из MainViewModel:**
```kotlin
val mainState by mainViewModel.uiState.collectAsState()
val bluetoothReady = mainState.bluetoothReady
```

**4b. Добавить статус Bluetooth в строку со статусом Wi-Fi (SensorTab):**
Аналогично JournalScreen — заменить `Text` на `Row` с двумя статусами.

**4c. Блокировка интерфейса SensorTab при выключенном Bluetooth:**
Обернуть содержимое `SensorTab` (после заголовка и статуса) в условие:
```kotlin
if (bluetoothReady) {
    // существующий контент SensorTab
} else {
    Text(
        text = stringResource(R.string.status_bluetooth_off),
        fontSize = 14.sp,
        fontWeight = FontWeight.Bold,
        color = MaterialTheme.colorScheme.error,
        modifier = Modifier.padding(vertical = 16.dp)
    )
}
```

## Влияние
- 4 файла: `strings.xml`, `strings-en.xml`, `JournalScreen.kt`, `SettingsScreen.kt`
- `MainViewModel.kt`, `MainActivity.kt` — не трогаем (BroadcastReceiver уже работает)
- Статус Bluetooth берётся из `mainViewModel.uiState.bluetoothReady` (обновляется автоматически)

## Верификация
1. Собрать: `./gradlew assembleDebug`
2. Журнал, Bluetooth включён — зелёный "🔵 Bluetooth включён" рядом с Wi-Fi
3. Журнал, Bluetooth выключен — красный "🔴 Bluetooth выключен", кнопка "Считать данные" заблокирована
4. Настройки → Настроить датчик, Bluetooth включён — зелёный статус, интерфейс активен
5. Настройки → Настроить датчик, Bluetooth выключен — красный статус, интерфейс заблокирован
6. Переключать Bluetooth через шторку — статус обновляется мгновенно
