# BTHome Viewer Lite
[![Release](https://img.shields.io/github/v/release/mikuz0/bthviewing?include_prereleases&label=Download)](https://github.com/mikuz0/bthviewing/releases/latest)
[![Android CI](https://github.com/mikuz0/bthviewing/actions/workflows/android.yml/badge.svg)](https://github.com/mikuz0/bthviewing/actions/workflows/android.yml)
Android-приложение для просмотра данных с датчиков, передающих данные по протоколу **BTHome** через **Bluetooth Low Energy (BLE)**.

## Возможности

### Экран «Устройства»
- **Сканирование BLE-устройств** — поиск и отображение всех видимых BLE-устройств
- **Фильтрация BTHome** — опция показа только устройств с данными BTHome
- **Прослушивание в реальном времени** — автоматическое получение данных от выбранного датчика
  - Температура, влажность, заряд батареи, напряжение, RSSI
  - Обновление каждую секунду
- **Статус подключения** — отображение состояния Bluetooth, Wi-Fi и разрешений

### Экран «Журнал»
- **Чтение истории** — загрузка всех записей из памяти датчика
- **Таблица записей** — время, температура, влажность
- **График** — визуализация температуры и влажности за выбранный период (6ч, сутки, неделя, месяц, год)
- **Экспорт CSV** — сохранение истории в CSV-файл, совместимый с [GraphMemo.html](https://github.com/geda/bthome-tools)
- **Переключатель времени** — отображение записей в UTC или местном часовом поясе

### Экран «Настройки»
- **Настроить датчик**
  - Просмотр и редактирование коэффициентов калибровки (температура, влажность)
  - Установка времени датчика
  - Очистка истории на датчике
- **Настроить приложение**
  - Тёмная тема
  - Блокировка портретной ориентации
  - Очистка списка устройств

## Поддерживаемые датчики

Приложение поддерживает датчики, использующие протокол **BTHome v2** ([bthome.io](https://bthome.io/format/)).

## Требования

- **Android 6.0 (API 23) и выше**
- **Bluetooth LE** (обязательна аппаратная поддержка устройства)

### Разрешения

| Разрешение | Версия Android | Назначение |
|---|---|---|
| `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT` | 12+ (API 31+) | Сканирование и подключение по BLE |
| `BLUETOOTH`, `BLUETOOTH_ADMIN` | ≤ 11 (API 30 и ниже) | Сканирование и подключение по BLE |
| `ACCESS_FINE_LOCATION` | ≤ 11 (API 30 и ниже) | Требуется для BLE-сканирования на Android ≤ 11 |
| `ACCESS_WIFI_STATE` | Все версии | Проверка статуса Wi-Fi |

> **Важно:** Wi-Fi (2.4 ГГц) может мешать BLE-сканированию. Рекомендуется отключать Wi-Fi при использовании приложения.

## Использование

### 1. Сканирование устройств
1. Нажмите **«Обновить список устройств»**
2. Дождитесь завершения сканирования
3. Выберите датчик из списка

### 2. Просмотр данных
- На экране «Устройства» данные отображаются в реальном времени
- На экране «Журнал» можно загрузить историю из памяти датчика

### 3. Экспорт истории
1. Перейдите на экран «Журнал»
2. Нажмите кнопку **«Экспорт CSV»**
3. Выберите место сохранения файла

### 4. Настройка датчика
1. Перейдите на экран «Настройки» → вкладка «Настроить датчик»
2. Нажмите **«Показать коэффициенты»** для просмотра текущих значений
3. Измените коэффициенты и нажмите **«Применить»**

## Техническая реализация

### Архитектура
- **Jetpack Compose** — современный UI
- **MVVM** — `MainViewModel`, `JournalViewModel`, `SettingsViewModel`
- **Kotlin Coroutines + Flow** — асинхронные операции
- **Navigation Compose** — навигация между экранами

### Стек технологий
- Kotlin 1.x
- Android Gradle Plugin
- Material Design 3
- BLE Scanner API
- GATT Client API

### Формат CSV
Экспортируемый CSV-файл совместим с инструментами [bthome-tools](https://github.com/geda/bthome-tools):

```
Time-Data=(A2/86400)+25569;Temp;Humi;Vbat
1700000000;21.34;55.20;3010
```

- `Time-Data` — время в формате, совместимом с Excel
- `Temp` — температура в °C
- `Humi` — влажность в %
- `Vbat` — напряжение батареи в мВ
